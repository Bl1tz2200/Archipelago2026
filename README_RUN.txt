2. Загрузите и распакуйте репозиторий Archipelago2026 без изменения структуры каталогов.
3. Откройте встроенный терминал VSCode и перейдите в каталог проекта:

   cd ~/Archipelago2026


ЕДИНАЯ КОМАНДА НА ВСЕ СИСТЕМЫ

Всё запускается одним Python-файлом run.py — он сам подхватывает окружение ROS 2
(source руками не нужен). Каким интерпретатором запустите run.py, тем же пойдут
и все дочерние скрипты — окружение Python выбираете вы:

   python3 run.py check      наземная проверка ВСЕХ систем подряд (пропеллеры сняты):
                             поле меток → распознавание «яблок» → расчёт маршрута
   python3 run.py mission    зачётный полёт: навигация по меткам + поиск «яблок»
   python3 run.py mission --alt 2.0 --no-land   те же ключи, что у run_leader.py

   python3 run.py flight --alt 0.5 --speed 0.3  ПРОСТОЙ ПОЛЁТ: арм → взлёт → змейка
                             по всему полю → посадка. Без «яблок», роя и бюджета —
                             этим проверяют, что дрон вообще летает по полю.
                             Маршрут без дрона: python3 run.py flight --dry-run

   python3 run.py markers    только проверка поля меток
   python3 run.py apples     только распознавание «яблок»
   python3 run.py plan --start 42   расчёт маршрута без дрона
   python3 run.py sim        прогон миссии в симуляторе
   python3 run.py help       все команды

Свой интерпретатор — просто подставьте его вместо python3:

   ~/venv/bin/python3 run.py flight --alt 0.5
   ./run.py check                     (файл исполняемый, шебанг тянет python3)

Если окружение ROS 2 вы поднимаете сами, добавьте --no-ros — тогда run.py не
станет перезапускаться, чтобы вычитать setup.bash.

Полёт и распознавание «яблок» требуют телеметрии полётного контроллера. Если
python3 run.py check печатает «шаг завис и снят по таймеру» — телеметрия FCU не
идёт: проверьте ros2 topic hz /fmu/out/vehicle_status.

Если python3 run.py mission молчит и ничего не делает — это она же: get_telemetry()
без телеметрии FCU не возвращается никогда и не реагирует на Ctrl+C. У flight на
этот случай стоит сторож: он не зависнет, а через 6 секунд напишет, чего не
хватает. Начинать отладку полёта лучше с него.

Отдельные шаги ниже — то же самое «вручную».


ПРОВЕРКИ БЕЗ ПОЛЁТА (пропеллеры сняты)

4. Что видит камера над полем меток — ID, раскладка, полоса обзора:

   python3 snake_mission/tools/marker_check.py --duration 30

5. Распознаются ли «яблоки» под камерой:

   python3 apple_vision/run_apple_detect.py --duration 60

   Размеченный поток публикуется в /out_detection.

6. Расчёт маршрута без полёта — покрытие поля и оценка времени:

   python3 snake_mission/run_leader.py --dry-run --start 42


ПОЛЁТ

7. Зачётный запуск:

   python3 snake_mission/run_leader.py

Основные ключи:

   --alt 2.5        высота поиска, м (потолок 3.0)
   --speed 0.6      скорость перелёта между метками, м/с
   --no-land        не садиться: зависнуть на старте для этапа фигуры
   --strategy       auto | aruco_frame | visual — как лететь к метке

Пример:

   python3 snake_mission/run_leader.py --alt 2.0 --no-land


СТРУКТУРА

   snake_mission/    миссия лидера: поле, маршрут, навигация по меткам
   apple_vision/     распознавание «яблок»

Пороги цвета «яблок» лежат в apple_vision/config/apples.yaml. Под свет зала их надо
переснять на месте:

   python3 apple_vision/tools/calibrate_hsv.py --grab кадр.png

Подробности — в README.md, snake_mission/README.md и apple_vision/README.md.
